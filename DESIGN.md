# AgencyDesk interface conventions

The interface uses ordinary business screens with literal titles and clear next actions. This records the implemented October 3 simplification; it is not a user-approved branding identity.

- No logo is approved. Do not add a wordmark, invented symbol, fake initials, or decorative workspace selector.
- Use neutral surfaces: page #f7f7f5, white panels, text #20201e, secondary text #646460, borders #deded8, primary action #292927. Avoid a blue-led palette, gradients, glow, and decorative charts.
- Geist Sans; body and controls 14px, auxiliary labels 12–13px, screen headings 25–28px. Keep keyboard focus visible.
- Desktop has a 224px navigation sidebar. Mobile has a labeled dialog menu with focus containment and Escape dismissal. Keep navigation and main actions reachable.
- Prefer compact native tables with meaningful links. Horizontal scrolling stays inside named, keyboard-focusable regions. Use 42px minimum controls and readable form labels.
- Show create forms on demand with a clearly named disclosure. Preserve all business actions and permission checks.
- Use green, amber, and red only for meaningful status. Avoid fake metrics, placeholder profile controls, invented dates, and unsupported progress values.
- Demo records are fictional and read-only. Detail links work; mutation buttons are absent. Client demo views contain only the example client's shared records.

Removed complexity: fake wordmarks/profile controls, illustrative revenue chart, orbit/floating-card artwork, repeated marketing-style CRM slogans, decorative feature cards, and extra portal headings. Existing business features remain available through the simpler records and forms.

Verification: desktop/mobile browser inspection, keyboard navigation, automated WCAG A/AA checks, and authenticated inquiry → proposal acceptance → project delivery tests. Revisit only with concrete usability evidence or new user direction.
